# 对比上下文回归用例

## 品牌点名对比

前置：上一轮推荐结果依次为 Nike、Adidas、HOKA、特步四款跑鞋。

用户输入：`对比 Nike 和阿迪`

期望：
- 后端 compare payload 只包含 Nike 与 Adidas 两款商品。
- 不允许自动 fallback 到 HOKA / 特步等未点名商品。
- 前端对比表商品标签优先显示品牌短名，不展示完整长标题。

## 点名不足两款

前置：上一轮推荐结果依次为 Nike、Adidas、HOKA、特步四款跑鞋。

用户输入：`对比 Nike 和不存在牌子`

期望：
- 后端不返回任意两款兜底对比。
- 回复提示用户只匹配到一款点名商品，并建议使用“第一个和第二个”或说完整品牌名。

## 无明确目标

前置：上一轮推荐结果至少两款。

用户输入：`对比一下`

期望：
- 后端仍默认对比上一轮前两款商品。
- 前端对比表保持紧凑，不因商品标题过长出现竖排。
