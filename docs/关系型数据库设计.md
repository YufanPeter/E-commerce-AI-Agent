# 关系型数据库设计

本项目使用 SQLite3 存储 App 需要的结构化数据。当前数据库包含 5 张表：

| 表名 | 作用 |
| --- | --- |
| `products` | 商品基础信息 |
| `product_skus` | 商品 SKU 与规格价格 |
| `product_contents` | 商品详情长文案、FAQ、用户评价 |
| `users` | 用户信息，当前只有默认用户 |
| `cart_items` | 用户购物车条目 |

## products

作用：存储商品基础信息，用于商品列表、推荐卡片、商品详情页展示。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `product_id` | `TEXT PRIMARY KEY` | 商品 ID |
| `title` | `TEXT` | 商品标题 |
| `brand` | `TEXT` | 品牌 |
| `category` | `TEXT` | 一级类目 |
| `sub_category` | `TEXT` | 子类目 |
| `image_path` | `TEXT` | 本地商品图片路径 |
| `image_url` | `TEXT` | 商品图片 URL |
| `source_path` | `TEXT` | 来源 JSON 文件路径 |
| `status` | `TEXT` | 商品状态：`active` / `inactive` |
| `created_at` | `TEXT` | 创建时间 |
| `updated_at` | `TEXT` | 更新时间 |

## product_skus

作用：存储商品 JSON 中的 `skus` 数组。一个商品可以有多个 SKU，价格只保存在 SKU 维度。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `sku_id` | `TEXT PRIMARY KEY` | SKU ID |
| `product_id` | `TEXT` | 所属商品 ID |
| `properties_json` | `TEXT` | SKU 规格 JSON，例如 `{"容量":"120g","套装":"单支"}` |
| `price` | `REAL` | SKU 价格 |
| `stock_qty` | `INTEGER` | 库存数量 |
| `status` | `TEXT` | SKU 状态：`active` / `inactive` |
| `created_at` | `TEXT` | 创建时间 |
| `updated_at` | `TEXT` | 更新时间 |

## product_contents

作用：存储商品 JSON 中的 `rag_knowledge` 内容，供前端展示，也可作为 RAG 文档来源。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `product_id` | `TEXT PRIMARY KEY` | 商品 ID |
| `marketing_description` | `TEXT` | 商品营销/详情长文案 |
| `official_faq_json` | `TEXT` | 官方 FAQ JSON 数组 |
| `user_reviews_json` | `TEXT` | 用户评价 JSON 数组 |
| `created_at` | `TEXT` | 创建时间 |
| `updated_at` | `TEXT` | 更新时间 |

## users

作用：存储用户信息。MVP 阶段默认只有一个用户：`demo_user`。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `user_id` | `TEXT PRIMARY KEY` | 用户 ID |
| `nickname` | `TEXT` | 用户昵称 |
| `created_at` | `TEXT` | 创建时间 |
| `updated_at` | `TEXT` | 更新时间 |

## cart_items

作用：存储购物车条目。当前假设一个用户只有一个购物车，因此不单独设计 `carts` 表。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `cart_item_id` | `INTEGER PRIMARY KEY` | 购物车条目 ID |
| `user_id` | `TEXT` | 用户 ID |
| `product_id` | `TEXT` | 商品 ID |
| `sku_id` | `TEXT` | SKU ID |
| `selected_options_json` | `TEXT` | 加购时选择的规格 JSON |
| `quantity` | `INTEGER` | 加购数量 |
| `unit_price` | `REAL` | 加购时单价 |
| `selected` | `INTEGER` | 是否选中：`1` 选中，`0` 未选中 |
| `created_at` | `TEXT` | 创建时间 |
| `updated_at` | `TEXT` | 更新时间 |

## 导入脚本

运行以下命令可从 `data/*/data/*.json` 导入商品数据：

```bash
python3 server/scripts/import_product_data.py
```

导入后当前数据量：

| 表名 | 数量 |
| --- | ---: |
| `products` | 100 |
| `product_skus` | 585 |
| `product_contents` | 100 |
| `users` | 1 |
| `cart_items` | 0 |
